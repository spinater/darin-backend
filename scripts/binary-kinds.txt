# 🔑 **ทำไมที่นี่เป็นรายชื่อนามสกุลได้ ทั้งที่ใบ 193 เพิ่งสั่งห้ามไว้** — เพราะเป็นคนละคำถาม
# และหลักฐานที่ใช้ตอบก็คนละอย่าง:
#   · §4 ถามว่า "ไฟล์นี้อยู่ใต้กติกา 500 บรรทัดไหม" ⇒ ไบต์ของไฟล์ตอบได้เอง (`grep -Iq .`)
#     ⇒ รายชื่อนามสกุลที่นั่นคือ **สำเนาที่อ่อนกว่า** ของคำตอบที่มีอยู่แล้ว และขาดไปหนึ่งชนิด
#     = **เงียบ** (ไม่มีใครรู้ว่าไม่ได้ตรวจ) ⇒ ห้าม
#   · ใบนี้ถามว่า "ไฟล์นี้ **ตั้งใจ** ให้เป็น text ไหม" ⇒ ไบต์ตอบไม่ได้ **โดยนิยาม** เพราะไบต์
#     คือสิ่งที่เพิ่งเสียไป ⇒ หลักฐานที่เหลืออยู่คือ *ชื่อ* · และขาดไปหนึ่งชนิด = **แดงเสียงดัง**
#     ที่แก้ด้วยการเติมหนึ่งแถว ⇒ ผิดไปทางที่ส่งเสียงเสมอ ซึ่งเป็นเกณฑ์เดียวกับใบ 193 เป๊ะ
