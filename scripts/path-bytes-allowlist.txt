# จุดเรียก git ที่ **กิน stdout** แต่ `-z` ช่วยอะไรไม่ได้ — ตัวข้ามของ scripts/check-path-bytes.sh (ใบ 314)
#
# รูปแถว:  <พาธเทียบรากรีโป><TAB><subcommand><TAB><จำนวนจุด><TAB># ใบ NNN · เหตุผล
#
# · **ไม่มีเลขบรรทัด** — เลขบรรทัดเน่าทุกครั้งที่มีใครแก้ข้างบน (§2 rule 3: อ้างสัญลักษณ์ ห้ามอ้างเลข)
# · **มี `<จำนวนจุด>` และมันคือหัวใจของแถว** — คีย์ `พาธ+subcommand` เฉย ๆ เป็นแถวที่ *กว้างเกิน*:
#   วันที่มีใครเพิ่ม `git show --name-only` ลงไฟล์เดียวกัน แถวเดิมจะยกเว้นให้ฟรีโดยไม่มีใครเห็น
#   ⇒ ปักจำนวนไว้แล้วเทียบเป๊ะ (บทเรียนหมุด junit ใบ 298) · สองทิศ สองทางแก้ สองข้อความ
# · เทียบเป็น **สตริงตรงตัว ห้าม `case`** — `web/src/app/[locale]/(app)/…` เป็นไดเรกทอรีจริง (ใบ 190)
# · `-` ในช่อง subcommand = จุดที่เกต **อ่าน subcommand ไม่ออก** (คำสั่งถูกเก็บในอาเรย์/`"$@"`)

scripts/check-knowledge.sh	log	1	# ใบ 314 · `log -1 --format=%ct` คายเวลา unix ไม่ใช่พาธ · ใส่ `-z` จะเปลี่ยนค่าที่จับได้
