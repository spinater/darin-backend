## 1. เทรนเนอร์ (Trainer)

### 1.1 ระดับเทรนเนอร์ (Rank)
| รหัส | ระดับ |
|---|---|
| **ST** | Senior Trainer |
| **CT** | Certified Trainer |
| **PT** | Personal Trainer |

> เรทค่าสอนดูที่ §1.2 (ตาราง กิจกรรม × ระดับ)

### 1.2 ค่าสอน 1-on-1 — ตารางเรท (กิจกรรม × ระดับ) ✅ ยืนยันแล้ว

> **กฎ:** ใช้ **ตารางเรทตรงๆ** — แต่ละกิจกรรมมีเรทของตัวเองแยกตามระดับเทรนเนอร์

| กิจกรรม | PT (Personal) | CT (Certified) | ST (Senior) |
|---|---|---|---|
| **PT ทั่วไป** | 200 | 300 | 400 |
| **Pilates** | **300** | **400** | **500** |
| **ว่ายน้ำ** | **250** | **250** | **250** |

- Pilates = เรท PT ทั่วไป **+100** ทุกระดับ
- **ว่ายน้ำ = 250 เท่ากันทุกระดับ** (ไม่แยกตามระดับ)
- **ทุกช่องในตารางปรับได้เองในหน้า Admin** + เพิ่มกิจกรรมใหม่ได้ (ระบบเก็บเป็น matrix: activity × rank)

### 1.3 ฐานเงินเดือน + เครดิตสอนคลาส
- ฐานเงินเดือน **10,000/เดือน** (ปรับได้ รายคน)
- ฐานมี **เครดิตสอนคลาส 5,000** รวมอยู่แล้ว (ปรับได้)
- `ค่าสอนคลาสจ่ายเพิ่ม = max(0, มูลค่าคลาสที่สอนรวม − เครดิต)`
- มูลค่าคลาสมาจากการ **เก็บชั่วโมง/คาบสอนจริงในระบบ** (ไม่ต้องกรอกมือ)

### 1.4 ค่าสอนคลาส Group — กฎคิดราคา
คนเข้าจริง = คนจอง − no-show → **0 คน = 0 · 1–2 คน = ครึ่งราคา · ≥3 คน = เต็มราคา**

**ราคาเต็ม 13 คลาส (ปรับได้ทุกตัว):**
| คลาส | ฿ | คลาส | ฿ |
|---|---|---|---|
| Aqua Fit | 400 | Body Pump | 400 |
| Aqua Beats | 400 | Functional Training | 200 |
| TRX | 300 | Yoga Essential | 400 |
| Body Combat | 400 | LesMills Pilates | 400 |
| BOSU Class | 400 | Darin Pilates | 400 |
| Roller Stretch | 200 | Flow Stretch | 200 |
| Core Strength | 200 | | |

### 1.5 ค่าคอมขายแพ็คเกจ PT

| สถานการณ์ | เทรนเนอร์ได้ | คนส่งลีดได้ |
|---|---|---|
| **ปิดการขายเอง** (self-closed) | **10%** | — |
| **Sales/Counter ส่งลีด** → เทรนเนอร์ปิด | **7%** | 3% |
| **ลูกค้ามาจาก TikTok/คลิปของเทรนเนอร์** | คิดแบบ "มีคนส่งลีด" → **7% / 3%** | 3% → เจ้าของคลิป |

- ฐานคำนวณ: **ราคาขายสุทธิ** ของแพ็ค PT
- นับเฉพาะแพ็คที่ **ปิดการขายในเดือนนั้น** (ไม่ผูกกับชั่วโมงที่สอน)
- ⚠️ เคส TikTok: ถ้าเทรนเนอร์เจ้าของคลิป **ปิดเอง** จะได้ 7%+3% = 10% (เท่า self-closed) — ดู §7 ข้อ 2

### 1.6 Incentive (เพิ่ม % ค่าคอมเมื่อขายถึงเกณฑ์)
| ตัวแปร | ค่า default | ปรับได้ |
|---|---|---|
| เกณฑ์ยอด PT self-closed | **≥ 30,000 / เดือน** | ✅ |
| อัตราคอมปกติ | 10% | ✅ |
| อัตราคอม incentive | **12% หรือ 15%** (เลือก/ตั้งเอง) | ✅ |

- คำนวณ ณ สิ้นเดือน — ถ้าถึงเกณฑ์ → ใช้อัตรา incentive **กับยอดขายทั้งเดือน** (ย้อนหลัง)
- ✅ incentive นี้เพิ่มที่ **% ค่าคอม เท่านั้น**
- ❌ **ยกเลิก** incentive แบบเก่าที่บวกค่าสอน +30/ชม. (230/330/430) — ไม่ใช้แล้ว

### 1.7 สูตรรวมรายเดือน (เทรนเนอร์)
```
รายได้ = ฐานเงินเดือน (10,000)
       + ค่าสอน 1-on-1 (Σ ชั่วโมง × เรทตามระดับ/กิจกรรม)
       + max(0, มูลค่าคลาสที่สอน − เครดิตคลาส 5,000)
       + ยอด PT ปิดเอง × (10% หรือ 12–15% ถ้าถึงเกณฑ์ 30k)
       + ยอด PT จากลีด × 7%
       + ยอด PT ที่ตัวเองส่งลีด/คลิปให้คนอื่นปิด × 3%
```

## 2. เคาน์เตอร์ / Sales (Counter Staff)

### 2.1 ฐานเงินเดือน
- กำหนดรายคน — ปัจจุบัน **15,000** และ **12,000** (ปรับได้)

### 2.2 ค่าคอมขายสมาชิก
| กรณี | % |
|---|---|
| ขาย **Basic** | **5%** |
| ขาย **ราคาโปรโมชั่น** (ไม่ใช่ราคาเต็ม) ทุกชนิด | **5%** (คิดจากราคาโปรฯ ที่จ่ายจริง) |
| ขาย **ราคาเต็ม** Premium / Platinum / PT / Pilates | **10%** |

> ปรับได้ทุกอัตรา · ระบบตัดสิน "โปรฯ" จาก **ราคาจ่ายจริง < ราคาเต็มใน catalog**

### 2.3 ค่าคอม PT ฝั่ง Counter
| กรณี | % |
|---|---|
| ส่งลีดให้เทรนเนอร์ปิด | **3%** |
| ปิดการขายเอง (เช่น ลูกค้าซื้อ online) | **10%** |

### 2.4 OT
`OT = Σ max(0, ชั่วโมงทำงานรายวัน − 9) × 40 บาท` (เกณฑ์ 9 ชม. และเรท 40 ปรับได้)
→ import จาก Excel เครื่องสแกนนิ้ว

### 2.5 สูตรรวมรายเดือน (เคาน์เตอร์)
```
รายได้ = ฐานเงินเดือน
       + Σ (ยอดขายสมาชิก × 5% หรือ 10% ตามกรณี)
       + ยอด PT ที่ส่งลีด × 3%
       + ยอด PT ที่ปิดเอง × 10%
       + OT
       [ + ค่าคอมต่ออายุ / walk-in / สินค้าหน้าร้าน — TBD ]
```

## 4. Config ที่ต้องแก้ได้ในหน้า Admin (ห้าม hardcode)

1. ฐานเงินเดือน — รายคน (ทั้งเทรนเนอร์/เคาน์เตอร์)
2. เครดิตสอนคลาส (default 5,000) — รายคน
3. **ตารางเรทค่าสอน (กิจกรรม × ระดับ)** — แก้ได้ทุกช่อง + เพิ่มกิจกรรม/ระดับใหม่ได้
4. (รวมอยู่ในข้อ 3)
5. ราคาเต็มคลาสทั้ง 13 คลาส + เพิ่มคลาสใหม่ได้
6. กฎคลาส: เกณฑ์คนขั้นต่ำ (3) และสัดส่วนลด (ครึ่ง)
7. % คอมสมาชิก: basic / promo / full
8. % คอม PT: self-closed, lead-trainer, lead-referrer, counter-self
9. Incentive: เกณฑ์ยอด (30,000) + อัตรา incentive (12/15%)
10. OT: เกณฑ์ชั่วโมง (9) + เรท (40)
11. ราคา Course Extension: 15 วัน 500 / 30 วัน 900 / freeze 300
12. รอบจ่าย: ฐานวันที่ 31 · คอม+OT ภายในวันที่ 3

## 5. Data Model (payroll ส่วนเพิ่ม)

```prisma
model Staff {
  id           String  @id @default(cuid())
  name         String
  role         String  // owner | admin | counter | trainer
  rank         String? // ST | CT | PT  (เฉพาะ trainer)
  baseSalary   Int     @default(0)
  classCredit  Int     @default(0)
  active       Boolean @default(true)
}

model TeachRate {              // ตารางเรท กิจกรรม × ระดับ (แก้ได้ในหน้า admin)
  id       String @id @default(cuid())
  activity String                    // pt | pilates | swim_pair | ...
  rank     String                    // PT | CT | ST
  rate     Int
  @@unique([activity, rank])
}

model PayrollConfig {          // key-value ปรับได้ในหน้า admin
  key    String @id           // เช่น comm.pt.selfClosed, incentive.threshold
  value  String
  note   String?
}

model SaleAttribution {        // ใครได้คอมจากบิลไหน
  id           String @id @default(cuid())
  saleId       String          // อ้างบิล/แพ็คเกจ
  staffId      String
  role         String          // closer | referrer | content_owner
  percent      Float
  amount       Float
}

model Payslip {
  id        String @id @default(cuid())
  staffId   String
  period    String            // 2026-07
  base      Float
  teachPay  Float             // 1-on-1
  classPay  Float             // ส่วนเกินเครดิต
  commission Float
  otPay     Float
  net       Float
  status    String @default("draft")   // draft | approved | paid
  lines     PayslipLine[]
}

model PayslipLine {
  id        String @id @default(cuid())
  payslipId String
  label     String
  qty       Float
  rate      Float
  amount    Float
}
```
