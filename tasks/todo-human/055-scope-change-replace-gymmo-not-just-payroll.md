## 1. ⚠️ สิ่งที่เปลี่ยนไปทันที

ใบ 049–054 เขียนบนสมมติฐานว่า **"Gymmo คือแหล่งข้อมูล · แอปนี้คือชั้นคิดเงิน"**
ใบ 049 §8.2 ถึงกับเขียนว่า *"แอปนี้ไม่ได้มาแทน Gymmo"*

**ข้อนั้นยกเลิก** — เป้าหมายคือแทนทั้งหมด

### 🔑 ผลที่ใหญ่ที่สุด: การ import กลายเป็น **สะพาน** ไม่ใช่ปลายทาง

| | เดิม | ใหม่ |
|---|---|---|
| คาบสอนมาจากไหน | import จาก Gymmo **ตลอดไป** | **แอปสร้างเอง** จากการจอง + เช็คอิน |
| ตัว import คือ | สถาปัตยกรรมถาวร | **สะพานชั่วคราว จนกว่าจะแทนได้** |

⚠️ **แต่ import ยังต้องทำอยู่ดี และทำก่อน** — เพราะยิมรันบน Gymmo วันนี้
และจะรันต่อไปจนกว่าของใหม่จะแทนได้ครบ **งานนั้นไม่ได้เสียเปล่า**

## 2. รายการสิ่งที่ Gymmo ทำได้ — เก็บไว้ไม่ให้ตก

จาก [เว็บของ Gymmo เอง](https://www.gymmo.app/th/software-features) + หลักฐานในไฟล์ที่ linus ส่งมา

Gymmo มีสามส่วน: **Web Console** (หลังบ้าน) · **Console App** (หน้าเคาน์เตอร์บนมือถือ) ·
**Member App** (แอปลูกค้า ฟรี ทั้ง iOS/Android)

### 2.1 ฝั่งลูกค้า (Member App)

| ฟังก์ชัน | ใบที่ครอบแล้ว |
|---|---|
| **จองคลาส** | ❌ **ยังไม่มีใบ** |
| **Pick-a-seat — เลือกเครื่อง/ที่นั่งในคลาส** | ⚠️ 053 §7.2 แตะไว้ (Reformer 4 เครื่อง) |
| **Waitlist + แจ้งเตือนเมื่อมีที่ว่าง** | ⚠️ 053 §9.5 แตะไว้ (ใช้เป็นสัญญาณขยายคลาส) |
| **เช็คอินด้วยแอป** | ❌ **ยังไม่มีใบ** |
| ดูแพ็คของยิม / ประวัติการซื้อ | ⚠️ 051 บางส่วน |
| **แจ้งเตือนแพ็คใกล้หมดอายุอัตโนมัติ** | ⚠️ 053 มีวันหมดอายุ แต่ไม่มีการเตือน |
| แจ้งเตือน: อนุมัติการซื้อ · ยกเลิกคลาส · เตือนก่อนคลาส · คืนเงิน · ยืนยันการจอง | ❌ **ยังไม่มีใบ** |

### 2.3 🔑 สามอย่างที่แอปนี้มี แต่ **Gymmo ไม่มี**

| | ใบ |
|---|---|

| **KPI เลื่อนขั้นเทรนเนอร์** | 052 |

**นี่คือเหตุผลที่โปรเจกต์นี้เกิดขึ้นตั้งแต่แรก** — และต้องไม่หายไปตอนไล่ตามฟีเจอร์ของ Gymmo

## 3. ⛔ ความเสี่ยงที่ต้องพูดตรง ๆ ก่อนตัดสินใจ

### 3.1 แอปลูกค้าคืองานที่ใหญ่กว่าทุกใบรวมกัน

Gymmo มี **แอปมือถือ iOS + Android ที่สมาชิกของ darin ใช้อยู่แล้ว**
แทน 100% = ต้องมีของแทนที่ลูกค้า**ยอมย้ายไป** — ลูกค้าไม่ได้อยากเปลี่ยนแอป
และการทำแอปสองแพลตฟอร์ม + แจ้งเตือน push + ขึ้นสโตร์ **ไม่ใช่งานขนาดเดียวกับที่ทำมาทั้งหมด**

🔴 **PWA (เว็บที่ติดตั้งลงจอได้) พอไหม** — ถูกกว่ามาก ไม่ต้องขึ้นสโตร์ แต่ push บน iOS จำกัดกว่า

### 3.2 แทนระบบที่กำลังรันอยู่ = การย้ายบ้าน ไม่ใช่การเพิ่มฟีเจอร์

- ต้อง **export ข้อมูลทั้งหมดออกจาก Gymmo ได้** ไม่ใช่แค่ worklog
  🔴 Gymmo ให้ export อะไรได้บ้าง — สมาชิก · แพ็คคงเหลือ · ประวัติการจอง · ยอดขาย
- ต้อง**รันคู่ขนาน**ช่วงหนึ่ง ⇒ ช่วงนั้นจะมีข้อมูลสองที่ **ซึ่งคือปัญหาเดิมที่พยายามแก้**
- **สลับแล้วถอยกลับยาก** — ถ้าของใหม่พัง ยิมหยุดขายไม่ได้

### 3.3 ของที่ดูเล็กแต่แพง

**ใบกำกับภาษีอัตโนมัติ** — เป็นเรื่องกฎหมาย ไม่ใช่เรื่องหน้าจอ · ผิดแล้วมีค่าปรับ
**Open Gym check-in** — ถ้าผูกกับประตู/ฮาร์ดแวร์ จะมีของนอกซอฟต์แวร์เข้ามาเกี่ยว
🔴 darin ใช้สองอย่างนี้อยู่จริงไหม หรือเป็นฟีเจอร์ที่ Gymmo มีแต่ไม่ได้ใช้

## 4. ✅ ลำดับที่เสนอ — แทนจากหลังบ้านไปหน้าบ้าน

| เฟส | ทำอะไร | ทำไมลำดับนี้ |
|---|---|---|
| **1** | **เงินเดือน + import จาก Gymmo** (ใบ 048–053) | สิ่งที่ Gymmo ทำไม่ได้ และเจ็บอยู่ทุกเดือน · ไม่ต้องให้ใครเปลี่ยนพฤติกรรม |
| **2** | **การขาย + แพ็ค + วันหมดอายุ ในแอปนี้** (ใบ 051 · 053) | เริ่มเป็นเจ้าของข้อมูล แทนที่จะยืมมา |
| **3** | **คิวเทรนเนอร์ + KPI** (ใบ 052 · 054) | Gymmo ไม่มี ⇒ ได้ประโยชน์ทันทีโดยไม่ต้องแข่งกับของเดิม |
| **4** | **ตารางคลาส + จอง + เช็คอิน** | จุดที่เริ่มแทน Gymmo จริง ⇒ หลังจากนี้ import เลิกได้ |
| **5** | **แอปลูกค้า / PWA + แจ้งเตือน** | ใหญ่ที่สุด เสี่ยงที่สุด ทำท้ายสุด |
| **6** | ใบกำกับภาษี · สัญญาดิจิทัล · Open Gym | เฉพาะถ้า darin ใช้จริง |

🔑 **เฟส 1–3 ไม่แข่งกับ Gymmo เลย** — ทำแล้วได้ประโยชน์ทันทีไม่ว่าจะแทนสำเร็จหรือไม่
**เฟส 4 คือจุดที่ต้องตัดสินใจจริงว่าจะแทนไหม** เพราะก่อนหน้านั้นยังถอยได้ฟรี

## 5. 🔴 ที่ต้องสำรวจก่อนวางแผนเฟส 4 ขึ้นไป

1. **Gymmo export อะไรได้บ้าง** — สมาชิก · แพ็คคงเหลือ · ประวัติการจอง · ยอดขาย · การเช็คอิน
2. **สมาชิกใช้ Member App กันจริงแค่ไหน** — ถ้าน้อย การแทนง่ายขึ้นมาก
3. **darin ใช้ฟีเจอร์ไหนของ Gymmo จริง** — หลายอย่างอาจมีแต่ไม่ได้ใช้ (ใบกำกับภาษี · Open Gym · หลายสาขา)
4. **ค่า Gymmo เดือนละเท่าไหร่** — เป็นตัวเทียบว่าการแทนคุ้มไหม
5. **สัญญากับ Gymmo ผูกมัดถึงเมื่อไหร่**

## 6. ผลต่อใบที่เขียนไว้แล้ว

**ไม่มีใบไหนต้องทิ้ง** — ทุกใบยังถูกต้องในเนื้อหา เปลี่ยนแค่กรอบ:

- **ใบ 049 §8.2** — ประโยค *"แอปนี้ไม่ได้มาแทน Gymmo"* ⇒ **ยกเลิก** แทนด้วยใบนี้
- **ใบ 050** (กฎสองข้อล้างคิว) — ยังจำเป็น เพราะประวัติเก่ายังอยู่ในชีต
- **ใบ 051** (หน้าขาย) — จาก *"อาจไม่ต้องทำถ้า Gymmo มี"* ⇒ **ต้องทำแน่นอน**
- **ใบ 053** (วงจรชีวิตแพ็ค) — จาก *"เผื่อไว้"* ⇒ **เป็นแกนกลาง**
- **ใบ 054** (คิว) — ไม่เปลี่ยน · Gymmo ไม่มีอยู่แล้ว
