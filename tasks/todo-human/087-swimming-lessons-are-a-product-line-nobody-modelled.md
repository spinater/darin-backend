# คอร์สว่ายน้ำเด็ก — สินค้าอีกสายที่ยังไม่มีที่อยู่ในระบบ

⇒ **ไกรทัศนพงษ์ พลแสน = ครูสอนว่ายน้ำ** ซึ่งตอบคำถามใน 071 §1.2 ไปหนึ่งในสามคน

## 1. ราคาตามใบจริง (อายุ 4–12 ปี · ~50 นาที/ครั้ง · **ราคารวมค่าเข้าแล้ว**)

| คอร์ส | คน | ราคา/ท่าน | **รายได้ต่อคาบของยิม** |
|---|---|---|---|
| กลุ่ม | 3–5 | 2,000 | **6,000 – 10,000** |
| คู่ | 2 (ครู 1) | 3,000 | **6,000** |
| ส่วนตัว | 1 (ครู 1) | 3,500 | **3,500** |

### 🔑 สิ่งที่ตารางนี้บอกและใบราคาไม่ได้พูด

**กลุ่ม 3 คนให้รายได้เท่ากับคอร์สคู่พอดี (6,000)** แต่ครูต้องดูแลเด็กเพิ่มอีกคน
⇒ ช่วงที่คุ้มจริงคือ **กลุ่ม 4–5 คน (8,000–10,000)** ส่วนกลุ่ม 3 คนคือพื้น ไม่ใช่กำไร
· และคอร์สส่วนตัว (3,500) ให้รายได้ต่อคาบ **น้อยกว่าคอร์สคู่เกือบครึ่ง** ⇒ ถ้าครูมีเวลาจำกัด
คอร์สส่วนตัวคือตัวที่กินเวลาแพงที่สุดของยิม ไม่ใช่ตัวที่ทำเงินที่สุด

⇒ เรื่องนี้จะเห็นเองใน dashboard เมื่อระบบรู้จักสินค้าสายนี้ — วันนี้ยังไม่รู้จักเลย

## 2. 🔴 ใบราคาไม่ได้บอกว่า **คอร์สหนึ่งมีกี่ครั้ง**

เขียนแต่ "เรียนประมาณ 50 นาทีต่อครั้ง" กับราคาต่อท่าน
⇒ **ลูกค้าอ่านแล้วตอบไม่ได้ว่า 2,000 บาทซื้ออะไร** และระบบก็คิดราคาต่อครั้งไม่ได้

นี่ไม่ใช่แค่ช่องว่างของข้อมูล — เป็นช่องว่างของ**สื่อการตลาดเอง** ถ้าจำนวนครั้งอยู่ในโพสต์อื่น
ก็ควรอยู่ในใบนี้ด้วย เพราะใบนี้คือใบที่ลูกค้าเอาไปตัดสินใจ

## 3. มันไม่ใช่ "คลาส" ในความหมายของระบบวันนี้

| | คลาสใน Gymmo | **คอร์สว่ายน้ำ** |
|---|---|---|
| ขายยังไง | ลูกค้าจองรอบต่อรอบ | **ขายเป็นแพ็คล่วงหน้า** |
| จ่ายครูยังไง | ราคาคลาส × ตัวคูณคนเข้า | ❓ ยังไม่รู้ |
| ที่มาของข้อมูล | import จาก Gymmo | ❓ ไม่มีใน Gymmo |

⇒ รูปที่ใกล้ที่สุดคือ **แพ็ค PT** (ซื้อล่วงหน้า N ครั้ง แล้วตัดทีละครั้ง)
⇒ กฎวันหมดอายุ/แช่แข็ง/ต่ออายุของ [ใบ 053](../todo/053-package-lifecycle-expiry-extension-freeze.md)
**ต้องครอบสายนี้ด้วย** ไม่ใช่เขียนไว้เฉพาะ PT
· และตารางราคาจากชีต `ราคาสมาชิก` (ใบ 071 §2) **ไม่มีสายนี้อยู่เลย** ต้องเพิ่มเป็นหมวดของตัวเอง

🔑 ชีต `ว่ายน้ำ` ในไฟล์สมุดขายรายเทรนเนอร์ (ใบ 050 §4) น่าจะเป็นสมุดของคนนี้ —
**ขอไฟล์/ชีตนั้นแยกมาดู** จะได้รู้ทั้งจำนวนครั้งต่อคอร์สและวิธีจ่ายครูจากของจริง

## 4. 🔴 ห้าข้อที่ต้องตอบ

1. **คอร์สหนึ่งกี่ครั้ง** — และเท่ากันทุกแบบ (กลุ่ม/คู่/ส่วนตัว) ไหม
2. **ไกรทัศนพงษ์ได้ค่าตอบแทนยังไง** — รายคาบเท่าไหร่ · % ของยอดขาย · หรือเงินเดือน
   (นี่คือครึ่งที่ยังขาดของ 071 §1.2)
3. **กลุ่มไม่ครบ 3 คนทำยังไง** — เปิดสอนแล้วยิมรับภาระ · เลื่อนรอ · หรือขยับราคา
4. **คอร์สหมดอายุกี่วัน** และแช่แข็ง/ต่ออายุได้ไหม (ใบ 053)
5. **"ราคารวมค่าเข้า" หักเป็นต้นทุนของคอร์สไหม** — ถ้าเด็กที่ไม่ได้เป็นสมาชิกปกติต้องจ่ายค่าเข้า
   การรวมไว้คือรายได้ที่ยกไป ⇒ P&L ต้องเห็น ไม่งั้นกำไรของสายนี้จะดูสูงเกินจริง
