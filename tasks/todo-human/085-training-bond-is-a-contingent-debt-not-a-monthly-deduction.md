# สัญญาผูกพันการอบรม — เป็นหนี้แบบมีเงื่อนไข ไม่ใช่รายการหักรายเดือน

- status: todo-human
- รอ: **linus** (ข้อ 4 และ 5) · และ **ทนายแรงงาน** (ข้อ 3 — ไม่ใช่เรื่องที่ agent ตัดสิน)
- เกี่ยวกับ [021 คนลาออกกลางงวด](021-leaver-base-salary-proration.md) ·
  [071 §3 หักผ่อน](071-active-roster-price-table-and-deductions.md) ·
  [056 §5.2 ระบบโอนถ่ายลูกค้า](056-product-scope-three-surfaces.md)

linus ส่งร่างสัญญาผูกพันการอบรมมา 2026-09-24 — คอร์ส 60,000 บาท ผูกพัน 2 ปี
คู่สัญญาคือเทรนเนอร์ที่ยัง active อยู่คนหนึ่งในสามคน

⚠️ ใบนี้ไม่เก็บข้อมูลส่วนบุคคล (เลขบัตร · ที่อยู่ · อายุ) — เก็บเฉพาะ**กลไก**ที่ระบบต้องรองรับ

---

## 1. 🔑 มันไม่ใช่ของชนิดเดียวกับ "หักผ่อนรองเท้า"

| | หักผ่อน (ใบ 071 §3) | **ผูกพันการอบรม** |
|---|---|---|
| หักทุกเดือนไหม | ✅ ใช่ มีขั้นต่ำ ปรับได้ | ❌ **ไม่หักเลยสักบาท** ระหว่างที่ยังอยู่ |
| ยอดรู้ล่วงหน้าไหม | ✅ รู้ | ❌ **ขึ้นกับวันที่ลาออก** — ไม่มีตัวเลขจนกว่าจะเกิดเหตุ |
| เกิดขึ้นเมื่อไหร่ | ตอนก่อหนี้ | **ตอนลาออกก่อนครบกำหนดเท่านั้น** |
| ขึ้นสลิปรายเดือนไหม | ✅ ขึ้น | ❌ **ไม่ขึ้น** |

⇒ ถ้าเอาไปยัดใน `Deduction` เดียวกัน จะได้สลิปที่หักเงิน 60,000 จากคนที่ไม่ได้เป็นหนี้อะไรเลย
**นี่คือหนี้แบบมีเงื่อนไข (contingent) ต้องเป็นของมันเอง**

```
model TrainingBond {
  staffId, courseName, amount, completedAt, bondDays, active
}
```
- ไม่แตะสลิปรายเดือน · โผล่ที่**หน้าจอตอนปิดการจ้าง**เท่านั้น
- สูตรในร่าง: `ค่าชดใช้ = amount × วันที่เหลือ ÷ bondDays` — ตรวจแล้วสอดคล้องกับตัวอย่างในร่าง
  (60,000 × 365 ÷ 730 = 30,000) ⇒ ลงเป็นฟังก์ชันบริสุทธิ์ใน `lib/` ได้ตรง ๆ

## 2. ⛔ ข้อที่ระบบต้องไม่ทำเอง — หักออกจากสลิปใบสุดท้าย

ทางที่ง่ายที่สุดสำหรับโปรแกรมคือเอายอดชดใช้ไปลบออกจากเงินเดือนงวดสุดท้าย
🔴 **ห้ามทำโดยอัตโนมัติ** — พ.ร.บ.คุ้มครองแรงงาน **มาตรา 76** จำกัดการหักค่าจ้างไว้เฉพาะกรณี
ที่กฎหมายอนุญาต และหลายกรณีต้องมี**หนังสือยินยอมของลูกจ้าง**แยกต่างหาก
(⚠️ ผมไม่ใช่ทนาย — ข้อนี้ให้ทนายยืนยัน แต่**ระบบต้องออกแบบเผื่อว่าหักไม่ได้**)

⇒ ระบบควร **คำนวณและแสดงยอด + ออกเป็นรายการลูกหนี้แยก** ไม่ใช่ net ออกจากสลิปเงียบ ๆ
ให้คนตัดสินใจว่าจะเรียกเก็บยังไง

## 3. 🔴 สามข้อที่ต้องถามทนาย (ไม่ใช่เรื่องที่ agent ตอบ)

1. **มาตรา 76** — หักจากค่าจ้าง/ค่าชดเชยงวดสุดท้ายได้แค่ไหน ต้องมีหนังสือยินยอมแยกไหม
2. **ป.พ.พ. มาตรา 383 + พ.ร.บ.ข้อสัญญาที่ไม่เป็นธรรม พ.ศ. 2540** — ศาลลดเบี้ยปรับที่สูงเกินส่วนได้
   ⇒ 60,000 / ผูกพัน 2 ปี สมเหตุสมผลในสายตาศาลไหม (แบบลดหลั่นตามสัดส่วนอย่างในร่าง
   **ช่วยเรื่องนี้อยู่แล้ว** เพราะไม่ได้เรียกเต็มจำนวน)
3. สัญญานี้เป็นส่วนหนึ่งของสัญญาจ้าง หรือเป็นสัญญาแยก — มีผลต่อการบังคับคดี

## 4. ⚠️ ช่องในร่างที่ควรอุดก่อนให้ทนายตรวจ — 8 ข้อ

| # | ช่อง | ทำไมสำคัญ |
|---|---|---|
| 1 | **สอบไม่ผ่าน / ไม่จบหลักสูตร** | ข้อ 3 เริ่มนับ "ตั้งแต่วันสำเร็จการอบรม" ⇒ **ถ้าไม่สำเร็จ นาฬิกาไม่เคยเริ่ม และไม่มีข้อไหนเรียกเงินคืนได้เลย** — บริษัทจ่าย 60,000 แล้วไม่มีสิทธิอะไรเลย |
| 2 | **ตัวอย่างในข้อ 5 เขียน "ทำงานได้ 1 ปี"** | ขัดกับข้อ 3 ที่นับจากวันสำเร็จการอบรม ⇒ ต้องเขียนให้ตรงกันว่า **นับจากวันสำเร็จการอบรม** ไม่ใช่วันเริ่มงาน |
| 3 | **ถูกเลิกจ้างเพราะทำผิด** | ข้อ 6 ยกเว้นเฉพาะ "เลิกจ้างโดยพนักงานมิได้กระทำผิด" ⇒ ตีความได้ว่าผิดแล้วต้องชดใช้ แต่ไม่ได้เขียนตรง ๆ |
| 4 | **วิธีชำระคืน** | จ่ายทันที / ผ่อนกี่งวด / ดอกเบี้ยถ้าผิดนัด — ไม่มีสักข้อ |
| 5 | **ใบประกาศ/certificate อยู่กับใคร** | คอร์สแบบนี้ออกใบรับรองในชื่อบุคคล ไม่ใช่บริษัท |
| 6 | **ข้อ 4.3 กว้างเกินจนน่าจะบังคับไม่ได้** | "ห้ามเปิดเผยความรู้ที่ได้จากการอบรม" — ความรู้จากคอร์สครูสอนไม่ใช่ความลับทางการค้าของบริษัท และถ้าตีความกว้างจะ**ขัดกับข้อ 4.2 ที่ให้เอาความรู้มาใช้สอนลูกค้า** ⇒ ควรจำกัดเป็น "เอกสาร/สื่อการสอนของหลักสูตร และข้อมูลความลับของบริษัท" |
| 7 | **ไม่มีข้อห้ามไปทำงานคู่แข่ง** | ตั้งใจหรือลืม — ถ้าจะใส่ ต้องจำกัดพื้นที่/เวลาให้สมเหตุสมผล ไม่งั้นศาลไม่บังคับให้ |
| 8 | 🔑 **ไม่มีข้อผูกพันเรื่องส่งมอบงานลูกค้า** | **ข้อนี้มีค่ามากกว่าเงิน 60,000** — ใบ 056 §5.2 linus บอกเองว่าต้องมีระบบโอนถ่ายลูกค้าพร้อมโปรแกรมและข้อมูล ⇒ สัญญาควรผูกหน้าที่ **ส่งมอบรายชื่อลูกค้า · คาบคงเหลือ · โปรแกรมที่วางไว้** ให้ครบก่อนพ้นสภาพ · ของที่เจ็บจริงตอนเทรนเนอร์ออกคือลูกค้าที่ยังมีคาบเหลือ ไม่ใช่ค่าคอร์ส |

## 5. 🔴 สองข้อที่ต้องให้ linus ตอบ เพื่อให้ระบบทำต่อได้

1. **ตอนนี้มีสัญญาแบบนี้กี่ฉบับ ใครบ้าง ยอดเท่าไหร่ ครบกำหนดเมื่อไหร่** — ใบ 071 §3 ถาม
   "ใครมีหนี้ค้างบ้าง" ไว้แล้ว และนี่คือหนี้คนละชนิดที่ต้องตั้งค่าแยก
2. **ถ้าลาออกก่อนครบ จะเรียกเก็บยังไงในทางปฏิบัติ** — หักงวดสุดท้าย (ดูข้อ 2/3) · ให้ผ่อน ·
   หรือแล้วแต่กรณี ⇒ ตัวนี้ตัดสินว่าหน้าจอปิดการจ้างต้องมีอะไรบ้าง

## 6. ขอบเขตที่ทำได้เลยหลังตอบข้อ 5

- `TrainingBond` + ฟังก์ชันบริสุทธิ์คำนวณยอดชดใช้ ณ วันที่ลาออก (เทสได้โดยไม่ต้องมีฐาน)
- หน้าปิดการจ้าง: แสดงยอดชดใช้ **คู่กับ** การคิดฐานเงินเดือนตามสัดส่วน (ใบ 021) และ
  **เช็กลิสต์ส่งมอบลูกค้า** (ใบ 056 §5.2) — สามอย่างนี้เกิดพร้อมกันเสมอ ควรอยู่หน้าเดียวกัน
- 🔴 แตะเส้นทางเงิน ⇒ เลน `payroll-auditor` (§9)
