## 3. ⚠️ หักผ่อน — **ไม่ใช่งวดตายตัว** และข้อนี้ทำให้ของที่เขียนไว้ผิด

> *"มีขั้นต่ำที่ต้องจ่ายทุกเดือน แต่สามารถปรับได้ตามสมควร"*

### 3.1 สิ่งที่เคยเข้าใจผิด

สลิปจริงเขียน `รองเท้า 2/4` ⇒ ผมอ่านเป็น **แผนผ่อน 4 งวดเท่า ๆ กัน** และใบ 049 §7.2
เขียนไว้ว่า *"ตารางงวด ตั้งครั้งเดียวตอนเริ่มผ่อน"* — **ผิด**

🔴 **ถ้ายอดหักแต่ละเดือนปรับได้ คำว่า "งวด 2/4" ไม่มีความหมายที่แน่นอน** — หักน้อยกว่าขั้นต่ำ
เดือนหนึ่ง แล้ว `2/4` จะหมายถึงอะไร · ตัวเลขที่จริงเสมอคือ **หักไปแล้วเท่าไหร่ · เหลือเท่าไหร่**

### 3.2 รูปที่ควรเป็น

```
model Deduction {           // หนี้หนึ่งก้อน เช่น รองเท้า
  staffId, name, totalAmount, minPerMonth, active
}
model DeductionEntry {      // หักจริงเดือนไหน เท่าไหร่ — ปรับได้รายเดือน
  payslipId, deductionId, amount, note
}
```

- ยอดตั้งต้นของเดือน = `minPerMonth` (กรอกครั้งเดียวตอนเริ่ม) · **แก้ได้ก่อนอนุมัติสลิป**
- ยอดคงเหลือ = `totalAmount − SUM(entries)` · หักจนเหลือ 0 แล้ว `active = false` เอง
- ⛔ **ห้ามหักเกินยอดคงเหลือ** — เป็นด่านที่ชั้นข้อมูล ไม่ใช่คำเตือนที่กดผ่านได้
- บนสลิปแสดง **`รองเท้า — หักเดือนนี้ 500 · เหลือ 1,500`** แทน `2/4`
  (ถ้า linus อยากเห็น `n/N` ต่อ ต้องยอมรับว่ามันเป็นค่าประมาณเมื่อยอดปรับได้)

### 3.3 🔴 ต้องตอบ

1. **"ปรับได้ตามสมควร" ใครปรับได้** — เจ้าของเท่านั้น หรือแอดมินด้วย
2. **ปรับต่ำกว่าขั้นต่ำได้ไหม** หรือขั้นต่ำคือพื้นจริง ๆ (ปรับได้แต่เพิ่มขึ้นเท่านั้น)
3. ตอนนี้ **ใครมีหนี้ค้างอยู่บ้าง ยอดเท่าไหร่ ขั้นต่ำเท่าไหร่** — ตั้งครั้งเดียวตอนเริ่มใช้ระบบ

**2026-09-25 ([091](091-linus-answers-2026-09-25-and-the-teaching-credit-kpi.md) §1, D2):** Q1 — *"เจ้าของเท่านั้น"* ⇒ ⛔ **only the owner may adjust an instalment**,
enforced **at the data layer** (a role check in the write path, not a hidden button) · Q2 — **still
open** · Q3 — partially: ใบ 090 records one live debt (พี่แพท, bicycle, 150,000) whose instalments
sum to 150,000 while its own note says 1,950 remains — the example of why §3.2 derives the balance
instead of storing it. The owner-only guard touches money ⇒ `payroll-auditor` (§9).
